## Structure: 2-week cycle

His program is an **8-session asynchronous cycle** (Pull#1, Push#1, Legs#1, Arms#1, Pull#2, Push#2, Legs#2, Arms#2) designed for a 10-day rotation. At 4 sessions/week it maps cleanly to **14 days**:

| | Tue | Wed | Fri | Sun |
|---|---|---|---|---|
| **Week A** | Pull #1 | Push #1 | Legs #1 | Arms #1 |
| **Week B** | Pull #2 | Push #2 | Legs #2 | Arms #2 |

One "program week" = 2 calendar weeks. Cost of 4 days/week: each muscle trained 2× per 14 days (~1×/week) instead of 2× per 10 days. Accepted tradeoff — total volume preserved, all 8 unique sessions kept.

## Block schedule (optimised: 4 program weeks per block, not 5)

Weeks 2–5 of each block are **identical** in sets/reps/RPE — only load climbs. Running all five adds 2 calendar weeks of no programmed change, so we run intro + 3 climb weeks per block.

| Program week | Calendar weeks | Sets | RPE (early/last) | Techniques |
|---|---|---|---|---|
| Block 1 W1 (intro) | 1–2 (Aug 18 – Aug 31) | 2 per exercise | ~7 / ~9 | None |
| Block 1 W2–W4 (climb) | 3–8 (Sep 1 – Oct 12) | 3 per exercise | ~8-9 / ~9-10 | ON |
| Block 2 W1 (intro) | 9–10 | 2 per exercise | ~7 / ~9 | None |
| Block 2 W2–W4 (grind) | 11–16 | 3 per exercise | ~8-9 / ~9-10 | ON |

Block 2 = different exercises + slightly higher rep ranges. Total ~16 weeks (~4 months) → lands near the 60kg target.

- 5–10 min general warm-up, then exercise-specific:

## Progression rules

1. Load is the only thing that climbs within a block. All sets at top of rep range at target RPE → +2.5kg next session.
2. Intro weeks: 2 sets, RPE ~7, no techniques. Find weights on new machines here.
3. Climb weeks: 3 sets, early sets RPE 8–9, **last set to failure** + listed technique.
4. RDL is capped at RPE 5–6 all block (his instruction — protects recovery).
5. Substitutions: use Option 1 / Option 2 from the Full Program sheet if equipment is unavailable.
6. Strength stall >3 weeks while eating at target → phase checkpoint, not exercise swap.

## Bulk/cut cycle strategy (曾礼智 framework, 165cm/56kg)

**Current phase: clean bulk from 56kg.**
- **Working target: 60–61kg (BMI ~22)**, confirmed. Reassess in mirror there before any push toward 65kg (BMI 24) ceiling. ETA ~5–7 months.
- End bulk early if: main-lift strength stalls >3 weeks despite eating at target, or appetite loss / neural fatigue appears.
- Light cardio 1–2 × 20 min/week for health is fine; no fat-loss cardio.

**Future cut (when triggered):**
- Floor 52–55kg (BMI 19–20). Never below BMI 19.
- **Strength floor: bench ≥1.16× bodyweight** (your pre-break level) — drop below, stop the cut.
- Cut macros: protein 2–2.5×BW (112–140g), carbs 1.5–2.4×BW (84–134g, or lean mass×3), fat 0.8–1×BW (45–56g). Optional 5 low-carb + 1 high-carb day.
- Deficit 300–500 kcal/day; ~100–200g/day loss mid-cut. First-month ~4kg water/glycogen drop is not fat loss.
- Body-fat % is an outcome, not a target.

**Annual rhythm:** bulk:cut ≥ 2:1.
