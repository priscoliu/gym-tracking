# Impeccable Design Context — WTW Data Solutions

## Design Context

### Users
**Primary**: Data analysts and business leaders (mixed audience).
- **Analysts** use Power BI daily — they need dense, scannable dashboards with clear signal vs noise.
- **Executives and managers** review KPIs in presentations and reports — they need instant comprehension, credibility, and polished visual delivery.
- Both audiences expect outputs that reflect WTW's standing as a global professional services firm.

### Brand Personality
**Modern · Confident · Clear · Precise · Global**

- Voice: Authoritative but not stiff. Data speaks; design amplifies.
- Tone: Professional, structured, premium — never playful or casual.
- Emotional goal: Confidence in the data. Trust in the system. Pride in the output.

### Brand Color System
- **Primary**: WTW Corporate Purple `#7C3AED`
- **Performance**: Outstanding `#16A34A` · Target Met `#22C55E` · Near Target `#F59E0B` · Below Target `#EF4444` · Critical `#DC2626`
- **Neutrals**: Dark text `#1E1B4B` · Body `#374151` · Muted `#6B7280` · Border `#E5E7EB` · Surface `#F9FAFB` · Canvas `#FFFFFF`
- **Theme**: Light mode only

### Aesthetic Direction
**Modern & polished** — purple accents used purposefully, subtle multi-layer shadows for card elevation, refined typography with clear hierarchy, generous whitespace around key metrics.

Anti-references (explicitly avoid):
- Generic Power BI defaults — blue bars, no visual hierarchy, default fonts
- Startup/playful aesthetic — rounded blobs, gradients everywhere, emoji in UI chrome
- Excel dump aesthetic — wall of numbers, no whitespace, no visual signal
- AI-generated aesthetic — glowing gradients, neon accents, over-engineered cards

Reference feel: A Bloomberg terminal crossed with a premium consulting firm deliverable — dense when needed, elegant always.

### Design Principles

1. **Data first, chrome last** — Every visual element must earn its place by helping the reader understand data faster. Decoration that doesn't carry information gets removed.

2. **Purple is the signal, white is the canvas** — Use `#7C3AED` purposefully for hierarchy, accent, and brand presence — not as decoration. White space is not empty; it is structure.

3. **Density with breathing room** — Pack meaning tightly, but give key numbers room to land. No walls of figures. The eye needs a place to rest between insights.

4. **Hierarchy through weight before colour** — Establish reading order through font size and weight first. Reserve colour for status (performance thresholds) and emphasis (primary metric).

5. **Corporate credibility** — Outputs must look like they were produced by a senior WTW analyst, not a BI tool or an AI. No emojis in code or UI chrome; no decorative gradients; no novelty. Emojis are acceptable inside Power BI HTML card visual content (status icons, badges).

### Technical Standards
- **Grid**: 12-column, 1280×720 or 1440×1080 canvas
- **Typography**: 12–72px scale; weight hierarchy for reading order
- **Shadows**: Multi-layer elevation system for card depth
- **Accessibility**: WCAG AA minimum
- **No emojis in code** — notebooks, scripts, DAX code, comments, print statements. Emojis are allowed in Power BI HTML card rendered visual content (status icons, badges).
