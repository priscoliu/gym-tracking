Strategic context
This analysis is built from PAS data transformed into a dedicated Gold Layer in Microsoft Fabric. The intent is speed and direction — not perfection. If the numbers are even directionally correct, the opportunity is too large to ignore.
The core thesis: the majority of our clients are significantly under-penetrated. Growth does not require finding new clients — it requires doing more with the clients who already trust us.
This document covers three layers of analysis, each building on the last:
Headline metrics — the numbers that get attention in a room
Dashboard design — how to visualise penetration, risk, and whitespace
Market basket analysis — product bundles and gap identification at scale, powered by PySpark
Headline metrics
The following metrics are designed to land with senior stakeholders. Each one reframes the cross-sell conversation from aspiration to evidence.
LOB penetration distribution
The single most powerful number: what percentage of clients have 2 or fewer lines of business? If the answer is 80%, the room should be uncomfortable. This is not a data point — it is a strategic indictment of under-penetration.
Revenue step-function by LOB count
Average revenue per client, segmented by number of LOBs held. If clients with 3+ LOBs generate 3–4x the revenue of single-LOB clients, that is not a cross-sell argument — it is an economic model. Every additional LOB added to an existing client is worth $X on average.

DAX formulas & implementation
All formulas assume a Gold Layer table (PAS_Gold) with: Company, Product, NetBrokerage, NetPremium. Additional columns (Industry, Region, Tier, Broker) enhance segmentation.
Count of products per client
LOB Count = 
CALCULATE(
    DISTINCTCOUNT( PAS_Gold[Product] ),
    ALLEXCEPT( PAS_Gold, PAS_Gold[Company] )
)
Average revenue per client
Avg Revenue Per Client = 
AVERAGEX(
    VALUES( PAS_Gold[Company] ),
    CALCULATE( SUM( PAS_Gold[NetBrokerage] ) )
)
Client LOB count (calculated column)
Client LOB Count = 
VAR _Count = 
    CALCULATE(
        DISTINCTCOUNT( PAS_Gold[Product] ),
        ALLEXCEPT( PAS_Gold, PAS_Gold[Company] )
    )
RETURN _Count
Revenue concentration — single-LOB clients
Single LOB Revenue % = 
DIVIDE(
    CALCULATE(
        SUM( PAS_Gold[NetBrokerage] ),
        FILTER(
            VALUES( PAS_Gold[Company] ),
            CALCULATE( DISTINCTCOUNT( PAS_Gold[Product] ) ) = 1
        )
    ),
    SUM( PAS_Gold[NetBrokerage] )
)
Product pair frequency (DAX)
Note: DAX handles pairs but struggles with triplets/quads at scale. For bundle sizes 3+, use PySpark (next section).
ProductPairs = 
VAR _Pairs = 
    GENERATE(
        SUMMARIZE( PAS_Gold, PAS_Gold[Company],
                   PAS_Gold[Product] ),
        VAR _CurrentCompany = PAS_Gold[Company]
        VAR _CurrentProduct = PAS_Gold[Product]
        RETURN
            CALCULATETABLE(
                DISTINCT( PAS_Gold[Product] ),
                PAS_Gold[Company] = _CurrentCompany,
                PAS_Gold[Product] > _CurrentProduct
            )
    )
RETURN _Pairs
Market basket analysis — PySpark
For triplet and quad bundles, computation belongs in the Fabric Gold Layer — a PySpark notebook that pre-computes bundles and writes to gold tables. DAX then reads and presents.
Why PySpark, not DAX
20 LOBs = 190 pairs, 1,140 triplets, 4,845 quads
DAX iterates row-by-row; PySpark distributes across Spark cluster
Pre-computed gold tables make Power BI fast and simple
Clean separation: Fabric does combinatorics, Power BI does presentation
Bundle computation
from pyspark.sql import SparkSession
from pyspark.sql.functions import (
    collect_set, size, col, explode, lit,
    array_sort, concat_ws, count, avg, row_number
)
from pyspark.sql.window import Window
from itertools import combinations
spark = SparkSession.builder.getOrCreate()
# 1. Load Gold Layer PAS data
df = spark.read.format('delta').load(
    'abfss://<workspace>@onelake.dfs.fabric.microsoft.com/
     <lakehouse>.Lakehouse/Tables/pas_gold'
)
# 2. Build client product sets
client_products = (
    df.groupBy('Company')
    .agg(
        collect_set('Product').alias('products'),
        size(collect_set('Product')).alias('lob_count'),
    )
)
# 3. UDF for combinations
from pyspark.sql.types import ArrayType, StringType
from pyspark.sql.functions import udf
def generate_combos(products, bundle_size):
    if not products or len(products) < bundle_size:
        return []
    return ['|'.join(c)
            for c in combinations(sorted(products),
                                  bundle_size)]
combo_udf = udf(
    lambda prods, n: generate_combos(prods, n),
    ArrayType(StringType())
)
# 4. Top bundles at each depth
TOP_N = 10
results = []
for bundle_size in [2, 3, 4]:
    bundles = (
        client_products
        .filter(col('lob_count') >= bundle_size)
        .withColumn('bundle',
            explode(combo_udf(
                col('products'), lit(bundle_size))))
        .groupBy('bundle')
        .agg(count('*').alias('client_count'))
        .withColumn('rank', row_number().over(
            Window.orderBy(
                col('client_count').desc())))
        .filter(col('rank') <= TOP_N)
        .withColumn('bundle_size',
                    lit(bundle_size))
    )
    results.append(bundles)
all_bundles = results[0]
for r in results[1:]:
    all_bundles = all_bundles.unionByName(
        r, allowMissingColumns=True)
# 5. Write to Gold table
all_bundles.write.format('delta')
    .mode('overwrite').save(
    '...Tables/gold_product_bundles')
Gap analysis — missing bundle components
Flags clients who partially match a high-frequency bundle but are missing one or more components. This is the actionable cross-sell output.
from pyspark.sql.functions import (
    array_except, split
)
top_bundles = (
    spark.read.format('delta')
    .load('...Tables/gold_product_bundles')
    .filter(col('client_count') >= 50)
    .select('bundle','bundle_size',
            'client_count')
)
gaps = (
    client_products
    .crossJoin(top_bundles)
    .withColumn('bundle_products',
        split(col('bundle'), '\\|'))
    .withColumn('missing',
        array_except(
            col('bundle_products'),
            col('products')))
    .withColumn('missing_count',
        size(col('missing')))
    .filter(
        (col('missing_count') >= 1) &
        (col('missing_count') <= 2))
    .select('Company', 'bundle',
            'bundle_size', 'client_count',
            'missing', 'missing_count')
)
gaps.write.format('delta')
    .mode('overwrite').save(
    '...Tables/gold_crosssell_gaps')
